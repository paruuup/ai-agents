## 🤖 Featured Project

### [AI-Powered Customer Feedback Automation](https://github.com/paruuup/customer-feedback-automation)

> An end-to-end intelligent workflow that transforms raw customer feedback into structured, actionable data — automatically.

| Layer | Tool |
|---|---|
| 🔧 Orchestration | n8n |
| 🧠 AI Classification | Groq / Llama 3 |
| 🗄️ Storage | Airtable |
| 🔔 Alerts | Slack |
| 📧 Responses | Gmail |

**What it does:**
- 📥 Captures feedback via form trigger
- 🤖 Uses LLM to classify into Complaints, Compliments, or Feature Requests
- 🔀 Routes data conditionally based on priority
- 📊 Logs everything to Airtable automatically
- 🔔 Sends real-time Slack alerts to the right team
